Cómo informarlo (APA 7)

Prefiere el intervalo Monte Carlo o bootstrap para decidir si hay mediación.

Cómo interpretarlo

El test de Sobel supone que ab sigue una distribución normal, lo que no suele cumplirse, y tiene poca potencia. Hoy se recomiendan los intervalos bootstrap o Monte Carlo (ver calculadora siguiente).

Ejemplo aplicado

El optimismo (X) predice el apoyo social percibido (M; a = 0,40), que a su vez predice el bienestar (Y; b = 0,35). El efecto indirecto ab = 0,14 es significativo con Sobel.

Los valores de ejemplo cargados en la calculadora corresponden a este caso.

Fórmulas

ab = a · b EE_Sobel = √(b²s_a² + a²s_b²) Aroian: √(b²s_a² + a²s_b² + s_a²s_b²) Goodman: √(b²s_a² + a²s_b² − s_a²s_b²)
