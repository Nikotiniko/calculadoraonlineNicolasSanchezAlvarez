Intervalo para un valor predicho

Calcula el valor predicho para un x₀, el intervalo de confianza de la media condicional y el intervalo de predicción para un caso individual.

Cómo informarlo (APA 7)

Cómo interpretarlo

El intervalo de predicción es siempre más ancho porque añade la variabilidad de cada caso. Ambos se ensanchan al alejarse de la media de X.

Ejemplo aplicado

Con la recta ŷ = 8,5 + 1,4x, para x₀ = 14 se predice 28,1. La media de quienes tienen x = 14 se estima con precisión, pero un caso concreto puede variar bastante más.

Los valores de ejemplo cargados en la calculadora corresponden a este caso.

Fórmulas

ŷ = b₀ + b₁x₀ h = 1/n + (x₀ − x̄)²/[(n − 1)s_x²] IC media: ŷ ± t·s_e√h Predicción: ŷ ± t·s_e√(1 + h)
