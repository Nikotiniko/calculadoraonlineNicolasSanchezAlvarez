t de Student para muestras independientes

Compara las medias de dos grupos independientes a partir de los estadísticos resumen. Incluye la corrección de Welch para varianzas distintas.

Cómo interpretarlo

La prueba de Welch no supone varianzas iguales y apenas pierde potencia cuando lo son, por lo que hoy se recomienda por defecto.

Ejemplo aplicado

Se compara un grupo que recibió un taller de habilidades sociales (n = 40) con un grupo control (n = 38). La diferencia de 2,7 puntos es significativa y moderada (d ≈ 0,50).

Los valores de ejemplo cargados en la calculadora corresponden a este caso.

Fórmulas

Student: t = (x̄₁ − x̄₂) / [Sp √(1/n₁ + 1/n₂)] Welch: t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂) gl Welch = (a + b)² / [a²/(n₁−1) + b²/(n₂−1)], a = s₁²/n₁, b = s₂²/n₂
