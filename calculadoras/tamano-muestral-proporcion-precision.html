Tamaño muestral para estimar una proporción

Calcula el tamaño muestral necesario para estimar un porcentaje con un margen de error dado, con corrección para poblaciones finitas.

Cómo informarlo (APA 7)

Cómo interpretarlo

p = 0,5 da el tamaño más conservador. El cálculo supone muestreo aleatorio simple; con muestreo por conglomerados hay que multiplicar por el efecto de diseño.

Ejemplo aplicado

Una encuesta de bienestar a los 8000 estudiantes de una facultad, con margen de ±5 % al 95 %, necesita 385 respuestas, o 368 con la corrección para población finita.

Los valores de ejemplo cargados en la calculadora corresponden a este caso.

Fórmulas

n₀ = z²p(1 − p)/e² n = n₀ / [1 + (n₀ − 1)/N]
